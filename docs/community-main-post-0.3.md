# 【MN 插件】Euclid Sketch——在卡片里直接画可计算的数学图

## 插件简介

Euclid Sketch 是一款在 MarginNote 里直接给数学题作图的场景插件。它不要求你先在别处画好再截图——面板本身就是一块可计算、可编辑的画布，函数曲线、几何图形、立体模型都在这块画布上生成，画完直接进卡片。

在 MN 里做数学笔记最难受的是画图：遇到 `f(x)=sin(x)+x/2` 或者一个圆锥，得先去 GeoGebra / 手画 → 截图 → 插回卡片；想改个参数，整条流程再来一遍。这个插件把那块「草稿纸」搬进 MN——图是活的：函数是表达式，角度是三个点，立体是参数模型，全部可以随手改。

全部计算在本地完成，不联网、不需要 API Key，笔记内容不会离开设备。

## 主要功能

**作图**

- **草稿纸画布**：单指画、双指平移缩放，14 色调色板；坐标系（网格 + 刻度）或空白画布两种背景，网格密度可选 1 / 5 / 10 / 50 / 100。
- **函数绘图**：科学计算器式输入面板，支持 `f(x)`、参数方程、圆/椭圆方程，可代入求值。
- **任意角度**：点三下画出角度并标注度数，两边等长；第三次按下可直接拖出第二条边，松手即为终点，也可拖端点或输入边长精确调整。
- **12 种几何图形**：圆 / 椭圆 / 圆弧 / 矩形 / 正多边形 / 星形 / 菱形 / 梯形 / 箭头 / 射线 / 直线 / 点，画完可拖控制点改。
- **曲线工具（钢笔式）**：逐点点击，按下后拖出的方向就是该点的切线，草稿层实时显示锚点与手柄；双击结束，画完直接拖手柄调曲率。
- **立体模型**：10 种常见几何体，透明 / 实体两种画法，实体模式下被挡住的棱自动画成虚线。

**参数与编辑**

- **几何参数面板**：所有图形都有 `位置 x / 位置 y`，改坐标即整体平移；线段可输入长度，圆输入半径，圆弧输入半径与起止角，角度输入边长。
- **按参数创建图形**：二次点击已在用的图形按钮（或长按 500ms），直接在视野中心放一个默认尺寸的图形并打开参数面板。
- **绘制实时参数**：画的过程中在图形旁显示长度、半径、宽高、角度，松手消失。
- **锁定半径**：开启后点一下即画与前一个等半径的圆。
- **笔宽三档**：细 / 中 / 粗一键切换，细调滑块保留。

**卡片与历史**

- **图片入卡**：插入当前题目卡或从文件导入任意图片，等比缩放不变形，导入即锁定防误擦。
- **复制草图**：整张草图复制到剪贴板，直接粘贴进卡片批注。
- **目标卡自动跟随**：在 MN 里点选哪张卡，插件顶栏就切到哪张（700ms 内），无需手动同步。
- **画布自动保存**：内容变化 1.2 秒后保存，关掉插件再打开还能接着画。
- **历史记录**：撤销按钮旁的时钟打开，按步列出（步号 + 当时图形数），任意一步都能「回到这里」；另存最近 5 份关闭前的完整画布，可整份恢复。
- **撤销重做与套索**：50 步撤销、框选后复制剪切粘贴、整组拖动，选中图形有虚线包围盒提示。

**界面**

- **迷你条**：面板收起后留一条浮条，可直接画点 / 线段 / 圆 / 角度、插入卡片图、复制草图；支持横向 / 竖向与按钮自定义。
- **工具栏四向停靠**：左 / 右竖排，上 / 下横排。
- **深色模式与窗口**：跟随 MN 白天 / 夜间，窗口可自由缩放、可收起。
- **诊断日志**：设置 → 关于 → 版本号连点 5 次开启调试模式，可复制日志反馈问题。
- **缓存管理**：设置 → 关于可查看画布 / 快照 / 设置各占多少，一键清理画布缓存。

## 安装与使用

1. 下载本帖末尾的两个包（`.mntemplate` 模板 + `.mnaddon` 插件），存进 iPad「文件」App。
2. **先装模板**：MarginNote → 设置 → 场景模板 → 管理场景模板 → 导入。
3. **再装插件**：MarginNote → 设置 → 插件 → 导入。
4. 打开任意学习集，在文档底部工具栏点插件胶囊唤出面板（顶部有 2D / 函数 / 3D 三档）。
5. 在文档里摘录题目——新摘录会自动成为「目标卡」，顶栏会显示卡名。
6. 点工具列的「插入卡片图」，题目渲染进画布，在图上画辅助线。

> 升级时 MN 对同版本或更低版本会跳过安装，请先删除设备上的旧包再导入新包。

## 功能详解

### 画布与手势

- 单指作图，双指平移 / 捏合缩放，捏合时中心内容保持不动。
- 手指作图可在设置里单独关闭，关闭后只有 Apple Pencil 与鼠标能落笔，避免手掌误触。
- 画布内容跨会话保留：关掉面板、切到别的卡片再回来，画布还在。

### 图形与参数

选中任意图形，绘图选项里会出现「几何参数」：

| 图形 | 可输入项 |
|---|---|
| 点 | 位置 x / y |
| 线段 | 位置 x / y、长度 |
| 圆 | 位置 x / y、半径 |
| 圆弧 | 位置 x / y、半径、起始角、终止角 |
| 角度 | 位置 x / y、边长（两边同步） |

改「位置」等于整体平移，形状和尺寸都不变。选中图形时，参数区只显示当前图形的参数，不会再混着那排「插入图形」按钮。

![几何参数](03-params.png)

### 角度

三下点击成角：第一下顶点，第二下第一条边，第三下开始拖第二条边——**拖动过程实时预览，松手处就是第二条边的终点**。两条边始终等长（教材画法），拖任意一个端点或直接输入边长都会同步更新。

接近 90° 时自动画成方角标记；开启特殊角吸附时，接近 15° 的整数倍会被吸附（容差 ±2.5°），普通角度不会被硬拽。

### 曲线（钢笔式）

- 点击 = 角点（两侧直线），按下后拖 = 平滑点（拖出的方向和长度决定这一处曲率）。
- 拖动过程中草稿层会画出锚点、蓝色虚线手柄和对称的入向手柄，拖多长弯多少当场可见。
- 双击结束，画完自动切回选择工具，此后点画布是选中而不是继续加点。
- 选中曲线后拖手柄可继续调整每一处的弯曲程度。

### 历史与自动保存

- 撤销按钮右侧的时钟按钮打开历史记录：按步列出「第 N 步 · 当时图形数」，点「回到这里」直接跳回那一步，不必连按撤销。
- 每次增删图形都会单独记一步；同一图形上的连续微调合并成一步，避免一步一撤。
- 弹窗下方是「上次关闭插件前的画布」，保留最近 5 份，可整份恢复。
- 缓存数据都在本机，可在设置 → 关于 → 缓存管理里查看占用并清理。

![历史记录](02-history.png)

### 界面可配置

- **迷你条**：收起后留下一条浮条，按钮可自选（画点 / 线段 / 圆 / 角度 / 插入卡片图 / 复制草图 / 展开 / 关闭），方向可选横向或竖向。
- **工具栏位置**：左 / 右竖排、上 / 下横排四向可选。

![迷你条](04-mini.png)

### 函数与立体

- 函数页用科学计算器式面板输入表达式，支持 `f(x)`、参数方程与圆/椭圆方程，可代入 `x` 求值。
- 立体页提供 10 种常见几何体，实体模式会自动把被遮挡的棱画成虚线。

![函数](05-function.png)

## 常见问题

**关掉插件后画的东西还在吗？**

在。本版开始画布会自动保存到本机，重开面板直接接着画。想找回更早的版本，用撤销按钮旁的时钟打开历史记录，恢复「上次关闭前的画布」。

**在原点画第二条线，为什么第一条被改了？**

这是 0.2.1 及更早版本的问题：手柄判定对所有工具都生效，起笔落在旧线段端点就被当成拖手柄。0.3.0 起手柄只在「选择」和「曲线」工具下响应，用线段工具在旧图形上起笔只会画新线。

**双指捏合放大后图形不见了？**

0.2.1 及更早版本在两指几乎重合时倍率会爆掉，视野跨度塌缩成 0，坐标算出来是 NaN，整片图形消失。0.3.0 已给倍率限幅、视野跨度加下限校验，正常捏合不会再出现。

**曲线的控制点很难点准？**

0.3.0 把「轻微移动算拖手柄」的阈值从 0.25 格提高到 0.5 格，双击结束时末尾重复的控制点也会自动丢弃。如果还是觉得不跟手，可以把笔宽调粗一点，采样会更稳。

**升级需要重设设置吗？**

不需要。颜色、笔宽、网格、工具栏与迷你条配置都会保留。首次升级后画布才开始自动保存，之前的画布不会自动补存。

**数据会上传到网络吗？**

不会。所有计算与存储都在本机，包括自动保存和历史快照，都在设备本地存储里。
