Euclid Sketch（MN5 场景插件）提交 0.2.1 版本更新，麻烦更新插件库里的版本。

主要变化（详见帖子更新记录）：
1. 目标卡自动跟随焦点卡，不再需要手动点「同步」
2. 新增曲线工具，画完可直接拖手柄调曲率
3. 圆弧改为自由绘制，可输入半径与起止角
4. 绘制全过程显示实时参数（线段长度、矩形宽高、圆半径等）
5. 计算器新增 ° / rad 单位键，`tan60°` 可直接计算
6. 修复：控制点拖动失效（iOS）、曲线点不中、笔拖被网格吸附、深色模式数字过暗等

两个包见附件（.mntemplate + .mnaddon），建议同时更新模板，因为卡片菜单命令由模板登记。
