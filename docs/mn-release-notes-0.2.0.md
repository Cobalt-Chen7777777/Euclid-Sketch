【场景插件】Euclid Sketch —— 在 MarginNote 里为数学题随手作图（0.2.0）

## 正文

**做数学题时，想直接在题目旁边画图？**

Euclid Sketch 是一个 MarginNote 5 场景插件：在你正看的题目卡片或文档页上打开一块轻量画布，随手画函数曲线、几何图形、手写标注，画完把整张草图**一键复制**，直接粘进卡片批注——题目和解题图就在一起了。

### ✨ 主要功能

**作图**
- 函数绘图：`f(x)`、参数方程、圆 / 椭圆方程，采样平滑、支持拖动查看
- 几何图元：线 / 点 / 圆 / 星形 / 菱形 / 梯形 / 箭头 / 角 / 圆弧 / 折线
- 手写笔迹、橡皮擦、套索框选（可整组拖动、复制粘贴）
- 撤销 / 重做（50 步）、选中图形快捷改色、虚线线型

**和卡片配合**
- **插入卡片图**：把当前题目卡渲染成图放进画布，在图上直接作辅助线
- **复制草图图片**：整张草图复制到剪贴板，粘进卡片批注即可
- **目标卡自动跟随**：在 MN 里摘录新题时自动成为作图目标；也可在卡片菜单里「设为草图目标卡」
- 图片锁定：题目底图不会被橡皮误擦；锁定/解锁一个徽标搞定

**工具**
- 计算器小窗：函数 / 算式双模式，可拖动，不挡画布

### 📥 安装

1. 下载 `Euclid Sketch-0.2.0.mntemplate`（模板）与 `Euclid Sketch-0.2.0.mnaddon`（插件）
2. 模板：MarginNote → 设置 → 场景模板 → 管理场景模板 → 导入
3. 插件：MarginNote → 设置 → 插件 → 导入

> ⚠️ 两个包建议都装：模板提供卡片菜单里的作图命令；只装插件时绘图与图片功能仍可用，但菜单命令不出现。
> ⚠️ MN 对同版本包会跳过安装，升级前请先删除旧插件 / 旧模板。
