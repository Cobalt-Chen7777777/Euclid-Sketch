# 社区帖更新记录（0.3.0-beta.1）

> 粘到帖子「更新记录」段的顶部，保持 `[details="..."]...[/details]` 折叠格式。

[details="Ver 0.3.0-beta.1 · 拖动/误触/消失集中修复，画布自动保存与历史记录"]

- 线段之前只能上下移动：判断坐标轴时 `x1/x2` 被当成 y 字段，水平方向完全不动；现在两轴都能拖。
- 单选图形拖不动：拖动判定只认套索多选，单选后是空的；现在按住当前选中的图形就能整组拖动。
- 在原点画第二条线会改到第一条：手柄判定对所有工具都生效，起笔落在旧线段端点就被当成拖手柄；现在只有选择和曲线工具会抢手柄。
- 画多了之后点别的工具没反应：真机偶尔收不到 pointerup，指针计数一直 ≥1，单指被当成双指；主指针落下时强制重置手势。
- 锁定的图片还能被套索选中/删掉：现在锁定即不可选、不可删，选框会跳过并提示。
- 角度第二边松手不生效：用的是 pointerup 坐标（WKWebView 里常为 0），改用拖动中最后一次位置，松手即刻成角。
- 角度两臂不等长：改成教材画法两边等长（取两次点击平均），拖任一臂都能改长度。
- 角度没画完切工具，切回来旧顶点又冒出来：切走就丢弃草稿。
- 双指捏合放大后图形整片消失：两指重合时倍率爆掉，视野跨度塌缩成 0，坐标变 NaN；现在倍率限幅、跨度有下限校验。
- 曲线整条不显示：平滑路径过滤坏点却没同步过滤切线，索引错位取到 undefined；现在点和切线一起过滤，坏控制点退化成直线。
- 曲线打点误触：轻微移动就被当成拖手柄、双击结束还多落一个点；阈值提到 0.5 格，重复点自动丢弃。
- 曲线画完仍停在曲线工具，点画布继续加点：现在画完自动切回选择工具。
- 套索选中没有任何视觉反馈：补上框选轨迹与多选包围盒。
- 检查更新提示读不清：从 11px 灰色副标题改成独立状态条。
- 新增：中文日志与调试模式——设置 → 关于 → 版本号连点 5 次，可复制诊断日志。
- 新增：**画布自动保存**——关掉插件再打开，画布还在，可以接着画。
- 新增：**历史记录弹窗**——撤销按钮旁的时钟，按步列出（步号 + 图形数），任意一步都能「回到这里」；还会保留最近 5 份关闭前的存档，可整份恢复。
- 新增：**缓存管理**（设置 → 关于），能看到画布 / 快照 / 设置各占多少，一键清理画布缓存。
- 新增：**几何参数带位置**——所有图形都能填 `位置 x / 位置 y`，改坐标即整体平移；选中图形时参数区不再混着「插入图形」那排按钮。
- 新增：**按参数创建图形**——二次点击已在用的图形按钮（或长按），直接在视野中心放一个默认尺寸的图形并打开参数。
- 新增：网格密度扩到 **1 / 5 / 10 / 50 / 100**；特殊角吸附容差收窄到 ±2.5°，普通角度不再被硬拽。
- 新增：**钢笔式曲线**——按下后拖出的方向就是该点的切线，草稿层实时画出锚点和手柄，拖多长弯多少当场可见。
- 新增：**迷你条可配置**——收起后的浮条支持横向 / 竖向切换，按钮可选（画点 / 线段 / 圆 / 角度 / 插入卡片图 / 复制草图 / 展开 / 关闭）。
- 新增：**工具栏四向停靠**——左 / 右竖排，上 / 下横排。
- 新增：卡片菜单多了一条「打开 Euclid Sketch」，长按卡片就能在脑图界面把面板叫出来。
- 修复：历史记录弹窗之前错位、遮罩只盖住顶栏（弹窗原先挂在带 transform 的工具栏里），现在改为覆盖整个面板。
- 修复：历史遮罩四角露出黑色直角，现在跟随面板圆角。
- 修复：首次进入打不开历史记录（按钮按撤销步数为 0 禁用），现在始终可点，能直接看到「上次关闭前的画布」。
- 修复：顶栏「函数」被挤成两行；历史图标不居中、与其他按钮不等高——三个按钮统一 30×30。
- 改进：历史弹窗瘦身，快照只列最近 3 份、日期单行、行高收紧，一屏看全不用滚。
- 改进：右上角同时有「收起」和「关闭」，不再强制常驻。
- 改进：撤销粒度调整为「增删图形各算一步」，属性微调仍合并，连点几个点可以逐个退回。
