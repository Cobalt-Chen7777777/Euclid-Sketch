## 插件简介

Euclid Sketch 是一款在 MarginNote 里直接给数学题作图的场景插件。它不要求你先在别处画好再截图——面板本身就是一块可计算、可编辑的画布，函数曲线、几何图形、立体模型都在这块画布上生成，画完直接进卡片。

在 MN 里做数学笔记最难受的是画图：遇到 `f(x)=sin(x)+x/2` 或者一个圆锥，得先去 GeoGebra / 手画 → 截图 → 插回卡片；想改个参数，整条流程再来一遍。这个插件把那块「草稿纸」搬进 MN——图是活的：函数是表达式，角度是三个点，立体是参数模型，全部可以随手改。

全部计算在本地完成，不联网、不需要 API Key，笔记内容不会离开设备。

> 当前版本：0.2.1-beta.1 测试版（稳定版 0.2.0）
> 作者：Cobalt

## 主要功能

- **草稿纸画布**：单指画、双指平移缩放，14 色调色板；坐标系（网格+刻度）或空白画布两种背景
- **函数绘图**：科学计算器式输入面板，支持 `f(x)`、参数方程、圆/椭圆方程，可代入求值
- **任意角度**：点三下画出角度并标注度数，接近 90° 自动画成方角
- **12 种几何图形**：圆 / 椭圆 / 圆弧 / 矩形 / 正多边形 / 星形 / 菱形 / 梯形 / 箭头 / 射线 / 直线 / 点，画完可拖控制点改
- **圆规工具**：吸附已有点、锁定半径连续画等圆
- **立体模型**：10 种常见几何体，透明 / 实体两种画法，实体模式下被挡住的棱自动画成虚线
- **数值控制**：选中线段输入精确长度、选中圆输入半径，单位为网格
- **图片入卡**：插入当前题目卡或从文件导入任意图片，等比缩放不变形，导入即锁定防误擦
- **复制草图**：整张草图复制到剪贴板，直接粘贴进卡片批注
- **目标卡四重保障**：摘录自动跟随 / 当前页推断 / 卡片菜单命令 / 顶栏同步
- **图层**：新建图层、切换当前绘制层、整层隐藏或锁定、选中图形移到指定层
- **撤销重做与套索**：50 步撤销、框选后复制剪切粘贴、整组拖动
- **深色模式与窗口**：跟随 MN 白天/夜间，窗口可自由缩放、可收起成迷你浮条
- **本地运行**：不联网、不上传任何笔记内容，不需要 AI 服务

## 安装与使用

1. 下载本帖末尾的两个包（`.mntemplate` 模板 + `.mnaddon` 插件），存进 iPad「文件」App
2. **先装模板**：MarginNote → 设置 → 场景模板 → 管理场景模板 → 导入
3. **再装插件**：MarginNote → 设置 → 插件 → 导入
4. 打开任意学习集，在文档底部工具栏点插件胶囊唤出面板（顶部有 2D / 函数 / 3D 三档）
5. 在文档里摘录题目——新摘录会自动成为「目标卡」，顶栏会显示卡名
6. 点工具列的「插入卡片图」，题目渲染进画布，在图上画辅助线
7. 画完点顶栏「复制」，回卡片批注长按粘贴

> **两个包建议都装**：卡片菜单里的「写入批注 / 导入此卡到草图 / 设为草图目标卡」由模板登记，只装插件时这些菜单项不会出现（面板的绘图与图片功能不受影响）。
> **升级注意**：MN 对同版本或更低版本的包会跳过安装。升级前请先在 设置 → 插件 / 场景模板 → 管理 里删掉旧包。

## 功能详解

### 画布与笔迹

- 单指作图、双指平移与捏合缩放；设置里可关掉「手指画图」，关掉后单指只平移，防止手写时误画
- 双击画布空白处无操作，所有手势都在画布内完成，不会带动面板窗口
- 14 色调色板固定两行，墨黑与灰排在最前（批注常用色）
- 两条独立的作图记录：手画笔迹（`ink`）与参数化图形彼此独立，「清除全部函数」不会删掉手画的图元

### 函数与计算器

- 15 个函数键（sin / cos / tan / asin / acos / atan / ln / log / exp / √ / abs / x² / π / e / 1⁄x）+ 20 键数字键盘
- 支持的写法：`f(x)`（如 `sin(x)+x/2`）、参数方程 `x=cos(t), y=sin(t)`、圆方程 `x^2+y^2=4`、椭圆方程（含平移）
- **代入求值**：`x=2` 时按 `=` 直接算出函数值，与绘图共用同一套求值器——能算的就能画
- 计算器小窗可拖动（拖顶部浮条）、两档尺寸，还可切「算式」模式直接算四则，如 `2+3×4`
- 曲线列表可逐条删除，或「清除全部函数」一键清空
- 三角函数固定使用**弧度**

### 几何作图

- **角度**：点顶点 → 第一条边 → 第二条边，度数标在圆弧上；接近 90° 自动改画方角标记；设置里可开「角度吸附特殊角」
- **12 种图形**：圆、椭圆、圆弧、矩形、正多边形（边数可调）、星形、菱形、梯形、箭头、射线、直线、点
- **圆规**：点圆心后拖半径，可吸附已有点；开启「锁定半径」可连续画等圆
- **数值微调**：选中线段后可在「绘图选项 → 几何参数」输入精确长度（锚定起点，只改长度不改方向）；选中圆可输入半径
- **套索**：框选后可复制 / 剪切 / 粘贴 / 删除，粘贴自动错位；框住多个图形可直接整组拖动
- **网格吸附**：拖动点、圆心、端点时除吸附已有点外，也会吸附到网格交点（设置可关）

### 立体模型

- 10 种：圆锥 / 圆柱 / 球 / 棱锥 / 圆环 / 正方体 / 长方体 / 圆台 / 棱台 / 半球
- **透明**（默认）：面半透明，能看到底面与背面结构
- **实体**：面不透明，被挡住的棱自动画成虚线（教材画法）
- 中性配色（纸白面 + 深色棱），不跟随调色板取色
- 单指旋转、双指缩放、参数滑块实时调整，可一键复位视角；3D 视图可导出 PNG

### 图片与卡片

- **插入卡片图**：把当前目标卡渲染成图放进画布，直接在题目图上作辅助线
- **从文件导入**：相册 / 文件 App 任意图片，自动压缩后保存
- **导入即锁定**：图片默认锁定，橡皮擦不掉（左上角蓝色锁徽标可解锁），避免画图时误擦题目
- **等比缩放**：拖右上角控制点始终按真实宽高比缩放，长图不变形；旧数据变形可一键「校正比例」
- **复制草图图片**：整张草图写进系统剪贴板，回卡片批注长按粘贴即可
- **写入批注**：把草图的结构化清单写进卡片批注（函数曲线带可复现公式），同一张卡只保留一条、原地更新，空画布不写入

### 目标卡：对哪张卡作图、写入哪张卡

顶栏显示当前目标卡，四种方式按可靠性排序：

1. **摘录自动跟随**：在 MN 里摘录新题产生新卡，自动成为作图目标
2. **当前页推断**：打开插件时自动识别当前文档页的题目卡
3. **卡片菜单命令**（需装模板）：脑图 / 文档里长按卡片 →「写入批注 / 导入此卡到草图 / 设为草图目标卡」
4. **顶栏同步**：点顶栏的卡片指示，随时对齐到 MN 当前聚焦卡

### 图层

「绘图选项 → 图层」里可新建图层、点图层名切换当前绘制层、整层显示/隐藏、整层锁定/解锁，以及把选中图形移到当前层。

- 层号越大越靠上，渲染与点选判定都按图层顺序
- **隐藏**：不渲染、不可点选、不导出（导出即所见即所得）
- **锁定**：不可选中、拖动、擦除，并以 45% 不透明度淡化显示；图片的「防误擦」锁不淡化
- 套索框选会自动跳过隐藏与锁定的图形
- 坐标轴是画布基准，不参与图层操作

### 窗口与主题

- 画布为主体：工具栏收在左侧悬浮列，参数收在可开合的「绘图选项」抽屉
- 拖右下角把手实时改尺寸（拖动中逐帧跟手），单击把手恢复默认尺寸
- 收起后是迷你浮条：品牌徽章 + 上一张 / 下一张卡片 + 展开 / 关闭
- 深色模式默认跟随 MN 的白天/夜间，也可手动锁定浅色 / 深色

## 常见问题

**装了插件，但底部工具栏没有入口？**

确认装的是 `.mntemplate` 模板，并且是通过「设置 → 场景模板 → 管理场景模板 → 导入」导入的。也可以直接在「设置 → 插件」列表里打开面板。

**卡片菜单里没有「设为草图目标卡」？**

这三个菜单命令由模板登记，只装 `.mnaddon` 时不会出现。补装模板包即可，面板本身的功能不受影响。

**插入了图片，拖控制点会变形？**

新版按图片真实宽高比缩放，不会变形。若遇到旧数据被拉变形的长图，选中图片后在「绘图选项 → 图片调整」点「校正比例」。

**橡皮擦不掉题目图？**

题目图导入即锁定（左上角蓝色锁徽标），点徽标解锁后才能擦——这是防误擦设计，画图时不会把题目擦掉。

**复制草图时提示「复制受限」，怎么把图放进卡片？**

这说明当前环境不允许写剪贴板（系统版本偏低，或面板不在安全上下文）。此时会自动弹出全屏大图，**长按图片 →「拷贝」或「存储到照片」**，再回卡片批注粘贴即可——这条路径不依赖剪贴板接口。

**升级后看不到任何变化？**

MN 对同版本或更低版本的包会跳过安装。请先删除旧插件和旧模板，再导入新包；或使用版本号更高的包。

**三角函数算出来的值和我预期不一样？**

目前固定使用弧度。输入 `sin(30)` 得到的是 sin(30 rad)，要算 30° 请写 `sin(30*pi/180)`。

**隐藏某个图层后，导出 PNG 里还会出现吗？**

不会。导出是所见即所得，隐藏的图形不会被渲染进图片。

**锁定图层为什么变淡了？**

这是刻意的视觉提示：45% 不透明度表示该层「看得见但动不了」。图片的防误擦锁不淡化，避免题目底图变淡影响做题。

**写入卡片和复制草图有什么区别？**

「复制草图」写的是**图片**，粘进批注后是一张图；「写入批注」写的是**文字清单**（图形类型、坐标、可复现的函数表达式），适合需要文字记录的场合。图片入卡推荐前者。
