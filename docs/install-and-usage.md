# Euclid Sketch · 安装与使用说明

> **插件名**：英文 **Euclid Sketch**（欧几里得 + 草稿，取「尺规作图」传统）。
> 中文界面里场景模板显示为「数学模型构图」，插件列表显示 `Euclid Sketch`。
> 当前版本 **0.2.0**（场景插件，纯面板形态）。

---

## 一、安装

需要 **MarginNote 5**（4.5.0+）。两个包建议都装：

| 包 | 作用 |
|---|---|
| `Euclid Sketch-0.2.0.mntemplate` | 场景模板：底部工具栏入口 + 卡片菜单里的作图命令 |
| `Euclid Sketch-0.2.0.mnaddon` | 插件本体：画布与全部功能 |

安装步骤：

1. 两个包下载到 iPad「文件」App（AirDrop / iCloud 均可）
2. **先装模板**：MarginNote → 设置 → 场景模板 → 管理场景模板 → 导入
3. **再装插件**：MarginNote → 设置 → 插件 → 导入

> ⚠️ **升级必读**：MN 对「同版本或更低版本」的包会跳过安装。升级前先在 设置 → 插件 / 场景模板 → 管理 里删除旧包，再导入新包。

---

## 二、打开面板

两种入口任选：

- **底部工具栏**：打开文档 / 学习集 → 底部工具栏点插件胶囊
- **文档记录模式**：摘录工具旁会出现「数学模型构图」入口

面板顶部分三档：**2D / 函数 / 3D**。

---

## 三、基本操作

### 2D 作图

- 左侧工具列：选择 / 画笔 / 橡皮 / 套索 / 角度 / 线 / 点 / 圆 / 全部图形 / 圆规 / 插入卡片图 / 绘图选项
- **单指画图，双指平移缩放**；设置里可关「手指画图」防误画
- 选中图形：拖控制点微调，蓝点 = 移动、绿点 = 等比缩放（拖不变形）
- 顶栏：撤销 / 重做、复制草图、目标卡指示

### 函数

- 底部计算器输入表达式 → 「绘制」加到画布
- `f(x)` 直接写表达式；圆 / 椭圆写方程；参数方程用 `x=cos(t), y=sin(t)`
- 「代入求值」：x 取某值时按 `=` 直接算
- 小窗可拖动（拖顶部浮条）、可切「算式」模式直接算数
- 曲线列表逐条删，或「清除全部函数」一键清

### 3D

- 选 10 种模型之一，拖参数滑块实时调整
- 切「透明 / 实体」：实体模式被挡住的棱自动画虚线

### 窗口

- 拖右下角把手实时缩放面板；单击把手恢复默认尺寸
- 收起后是迷你浮条：品牌徽章 + 上一张 / 下一张卡片 + 展开 / 关闭

## 四、对哪张卡片作图（目标卡）

顶栏显示当前目标卡，四种确定方式按可靠性排序：

1. **摘录自动跟随**：在 MN 里摘录新题 → 新卡自动成为目标
2. **当前页推断**：打开插件时自动识别当前文档页的题目卡
3. **卡片菜单命令**（需装模板）：长按卡片 →「设为草图目标卡」/「导入此卡到草图」/「写入批注」
4. **顶栏同步**：点顶栏卡片指示，对齐到 MN 当前聚焦卡

---

## 五、把图放进卡片

MN 未开放「图片写入卡片」接口，当前最短路径是**复制粘贴**：

1. 画完图 → 点顶栏**复制**按钮（或选项抽屉「复制草图图片」）
2. 回到卡片批注 → 长按 → 粘贴 → 草图以图片形式出现在批注里

另一种方式：选项抽屉「导出 PNG」→ 存相册 → 在 MN 里手动插入图片 / 子卡。

> 「写入批注」命令写的是**结构化文字清单**（含可复现的公式），适合需要文字记录的场合；画图本身推荐上面的复制粘贴。

## 六、常见问题

**Q：装了但底部工具栏没有入口？**
确认装的是 `mntemplate` 且已通过「场景模板 → 管理场景模板」导入；或直接用插件列表打开面板。

**Q：卡片菜单里没有「设为草图目标卡」？**
只装 `.mnaddon` 时菜单命令不出现，需补装模板包。

**Q：插入的图片变形了？**
选中图片 → 绘图选项 → 图片调整区 → 点「校正比例」；新插入的图自动按真实比例显示。

**Q：橡皮擦不掉题目图？**
题目图默认锁定（左上角蓝色锁徽标），点徽标解锁后才能擦；锁定是防误擦设计。

**Q：升级后没变化？**
MN 跳过了同版本安装——先删除旧插件 / 旧模板再导入。

## 七、数据与卸载

- 设置与画布内容存于面板本地（localStorage），删除插件即清除
- 需要保留草图时先「导出 PNG / JSON」（设置页与选项抽屉均有入口）
- 卸载：设置 → 插件 → 删除；模板：场景模板 → 管理 → 删除
