## ④ 功能详解 · 几何作图（改角度那条 + 追加两条）

**原文：**

```
- **角度**：点顶点 → 第一条边 → 第二条边，度数标在圆弧上；接近 90° 自动改画方角标记；设置里可开「角度吸附特殊角」
```

**替换为：**

```
- **角度**：点顶点 → 第一条边 → **第三条边按下后直接拖，松手处即为第二边终点**（拖动过程实时预览），度数标在圆弧上；两边始终等长，拖任一端点或输入边长都会同步；接近 90° 自动改画方角标记；特殊角吸附容差 ±2.5°，普通角度不会被硬拽
- **按参数创建**：二次点击已经在用的图形按钮（或长按 500ms），在视野中心生成默认尺寸的图形并自动打开「几何参数」，不必先画再改
- **几何参数带位置**：所有图形都能输入 `位置 x / 位置 y`（格），改坐标即整体平移，形状与尺寸不变
```

**原文「数值微调」那条：**

```
- **数值微调**：选中线段后可在「绘图选项 → 几何参数」输入精确长度（锚定起点，只改长度不改方向）；选中圆可输入半径
```

**替换为：**

```
- **数值微调**：选中线段输入精确长度（锚定起点，只改长度不改方向）、圆输入半径、圆弧输入半径与起止角、角度输入边长、任何图形输入位置 x / y；选中图形时参数区只显示当前图形的项
```

## ⑤ 功能详解 · 新增「曲线（钢笔式）」小节（插在「几何作图」之后、「立体模型」之前）

```
### 曲线（钢笔式）

- **点击 = 角点，拖 = 平滑点**：按下后拖出的方向与长度就是该点的出向切线，决定这一处曲率；松手后继续点下一个点，双击结束
- **草稿实时可见**：拖动过程中画出锚点、蓝色虚线手柄与对称的入向手柄，拖多长、往哪弯当场看清
- **打点不误触**：移动小于 0.5 格不算拖手柄（保持角点）；双击结束时末尾重复点自动丢弃
- **画完自动切回选择工具**，此后点画布是选中而不是继续加点
- 选中曲线后拖手柄可继续调整每一处的弯曲程度
```

## ⑥ 功能详解 · 新增「历史与自动保存」小节（插在「图层」之后、「窗口与主题」之前）

```
### 历史与自动保存

- **自动保存**：内容变化 1.2 秒后写入本机；关掉面板再打开直接接着画
- **历史记录弹窗**：撤销 / 重做右侧的时钟按钮打开，按步列出「第 N 步 · 当时图形数」，点「回到这里」直接跳回那一步，不必连按撤销
- **撤销粒度**：增删图形各算一步（连点几个点可以逐个退回）；同一图形上的连续微调合并成一步，避免一步一撤
- **关闭前快照**：图形增减 3 秒后留档，关闭面板 / 切后台时立即落盘，保留最近 5 份完整画布，可整份恢复
- **缓存管理**：设置 → 关于 → 缓存管理，可查看画布 / 快照 / 设置各占多少，一键清除画布缓存（不动设置）
```

## ⑧ 常见问题（在现有条目之后追加 4 条）

```
**关掉插件后画的东西还在吗？**

在。本版开始画布会自动保存到本机，重开面板直接接着画。想找回更早的版本，点撤销按钮旁的时钟，用「上次关闭插件前的画布」恢复。

**在原点画第二条线，为什么第一条被改了？**

0.2.1 及更早版本的问题：手柄判定对所有工具都生效，起笔落在旧线段端点就被当成拖手柄。0.3.0 起手柄只在「选择」和「曲线」工具下响应，用线段工具在旧图形上起笔只会画新线。

**双指捏合放大后图形不见了？**

0.2.1 及更早版本在两指几乎重合时倍率会爆掉，视野跨度塌缩成 0，坐标算出来是 NaN，整片图形消失。0.3.0 已给倍率限幅、视野跨度加下限校验，正常捏合不会再出现。

**曲线的控制点很难点准？**

0.3.0 把「轻微移动算拖手柄」的阈值从 0.25 格提高到 0.5 格，双击结束时末尾重复的控制点也会自动丢弃。如果还是觉得不跟手，可以把笔宽调粗一点，采样会更稳。

**升级需要重设设置吗？**

不需要。颜色、笔宽、网格、工具栏与迷你条配置都会保留。首次升级后画布才开始自动保存，之前的画布不会自动补存。
```

## ⑨ 更新记录（在 `Ver 0.2.1` 之前插入新版本）

```
Ver 0.3.0-beta.1 · 拖动与误触集中修复，画布自动保存与历史记录

- 新增画布自动保存与历史快照：关掉插件再打开还能接着画，保留最近 5 份关闭前的完整画布，可整份恢复。
- 新增历史记录弹窗：按步列出「第 N 步 · 当时图形数」，任意一步可「回到这里」，不必连按撤销。
- 新增几何参数「位置 x / y」：所有图形都能精确改坐标，改坐标即整体平移；选中图形时参数区只显示当前图形的项。
- 新增按参数创建图形：二次点击（或长按）图形按钮，在视野中心放默认尺寸的图形并自动打开参数面板。
- 新增钢笔式曲线：按下后拖出的方向即该点切线，拖动中实时显示锚点与手柄，双击结束，画完自动切回选择工具。
- 新增迷你条图形快建（点 / 线段 / 圆 / 角度）与按钮自定义、横竖切换；工具栏支持四向停靠。
- 新增网格密度 1 / 5 / 10 / 50 / 100；特殊角吸附容差从 ±4° 收窄到 ±2.5°。
- 新增诊断日志与调试模式（设置 → 关于 → 版本号连点 5 次，可复制日志）、缓存查看与清理。
- 新增卡片菜单「打开 Euclid Sketch」，长按卡片即可在脑图界面唤出面板。
- 修复线段只能上下移动：平移时用 `k.endsWith("x")` 判断坐标轴，`x1/x2` 落到 else 分支被加上了 dy，水平方向根本不动。
- 修复单选图形拖不动：拖动判定只认套索多选的 `selectionIds`，单选后为空；现在按住当前选中图形即可整组拖动。
- 修复在原点画第二条线会改到第一条：手柄判定原本对所有模式生效。
- 修复画多了之后点其他工具没反应：真机偶发收不到 pointerup，指针计数恒 ≥1，单指被当成双指。
- 修复锁定图片仍能被套索选中 / 删除：`isSelectable` 里留了 `|| type === "image"` 的例外；删除时也没查 `locked`。
- 修复角度第二边松手不生效：成角用的是 pointerup 坐标，WKWebView 里常为 0，改用拖动中最后一次已知位置。
- 角度两臂改为等长（取两次点击的平均），拖任一臂或输入边长都会同步。
- 修复角度没画完切工具、切回来旧顶点又出现：切走即清草稿。
- 修复双指捏合放大后图形整片消失（倍率爆炸 → 视野跨度塌缩成 0 → 坐标 NaN）；捏合平移也改用缩放前的视口尺寸。
- 修复曲线整条不渲染：平滑路径过滤了坏点却没同步过滤切线，索引错位取到 `undefined`，视口异常时控制点全变 NaN。
- 修复曲线打点误触：轻微移动不再变成平滑点，双击结束不再多落一点。
- 修复套索选中没有任何视觉反馈，补上框选轨迹与多选包围盒。
- 修复历史弹窗错位、遮罩只盖住顶栏（弹窗挂在带 transform 的工具栏里）；遮罩四角补圆角。
- 修复首次进入打不开历史记录（按钮按撤销步数为 0 禁用），改为始终可点。
- 修复顶栏「函数」折成两行；历史图标不居中、与其他按钮不等高，三个按钮统一 30×30。
- 改进检查更新提示：从灰色小字改为独立状态条（成功绿 / 失败红）。
- 改进撤销粒度：增删图形各算一步，连点几个可逐个退回。
```
